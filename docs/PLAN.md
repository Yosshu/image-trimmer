# 実装計画

仕様は [SPEC.md](./SPEC.md) を参照。

## 方針
- 最初に公開の仕組みを作り、各段階を GitHub Pages 上で本家のフォトと見比べられるようにする
- 一番難しい計算部分（回転・枠の制限・比率の切り替え）を先に作り、テストで固める
- 画面は見た目を作ってから、操作を1つずつ足していく

## 段階

| # | 段階 | 内容 | 確認方法 |
|---|---|---|---|
| 0 | 土台 | Vite + TypeScript、Vitest、GitHub Actions で Pages に自動公開 | 公開 URL が開ける |
| 1 | 計算部分 | 回転時の最小拡大率、枠の制限、画像のスライドの制限、比率切り替え（中心を保って最大）、画面へのフィット、ズームの上限・下限 | 自動テスト（スクショの実測値を正解データにする） |
| 2 | 見た目 | 開始画面（開く・ドラッグ＆ドロップ・貼り付け）、編集画面の配置、配色（ダーク・ライト）、アイコン、画像と枠の描画、各部品（まだ動かない） | 125%・同じ画面サイズで自動スクショを撮り、本家のスクショと並べて比べる |
| 3 | 角度スライダー | 目盛りが流れるスライダー、角度の表示、回転時の自動拡大、ズーム率の更新 | スクショ比較 |
| 4 | 枠のドラッグ | 四隅・各辺のハンドル、画像のスライド、グリッドとサイズ表示、離したら中央に戻って拡大するアニメーション | Pages で操作感を確認 |
| 5 | 回転・反転・比率 | 90° 回転（枠も一緒に回る）、反転、比率ピッカー、比率ラベル | 本家と同じ操作で比較 |
| 6 | ズームと履歴 | ズーム（枠は固定）、ボタンの有効・無効の切り替え、ホイール、リセット、元に戻す・やり直し、矢印キー | 本家と同じ操作で比較 |
| 7 | 保存 | コピーとして保存（保存ダイアログ）、PNG / JPEG / TIFF / BMP、クリップボードにコピー、キャンセル | 書き出し結果の自動テスト |
| 8 | 仕上げ | ツールチップ、ライトテーマ、スマホ・タッチ、細部の調整、README | 全体確認 |

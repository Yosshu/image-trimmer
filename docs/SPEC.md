# image-trimmer 仕様書（Windows フォト「トリミング」再現）

Windows 11 の「フォト」アプリ → 画像の編集 → **トリミング** ツールを、UI・挙動ともに Web 上で再現し、GitHub Pages で公開する。

- 再現対象：ユーザー提供スクリーンショットのバージョン（2026年10月時点の安定版。編集画面上部にツールアイコンが6つ並ぶ版）
- 範囲外：調整・フィルター・マークアップ・消去・背景などトリミング以外の編集ツール（**アイコン自体も置かない**）
- 画像はブラウザ内だけで処理し、外部へ送信しない

> 凡例：**【確定】** スクショ／ユーザー回答で確認済み、**【未確定】** 要確認（§8 に一覧）、**【Web独自】** 本家にない Web 版だけの要素

## 1. 画面構成

### 1.1 全体
- 背景色（ダーク）：`#202020` 【確定】
- 画像の描画領域は、上部ツールバーの下からウィンドウ下端までの全面。下部の角度スライダーやボタン列は、画像の**上に重なって**表示される（回転して大きくなった画像はスライダーの裏まで見える）【確定】
- トリミング枠は、ツールバーとスライダーに挟まれた領域の中央に、縦横比を保ったまま最大サイズでフィットさせる 【確定】
  - 実測：ウィンドウ 1902×970 のとき、枠の最大の高さは約 602px（y=172〜774）

### 1.2 上部ツールバー 【確定】
| 位置 | 要素 | 備考 |
|---|---|---|
| 左グループ | ズームイン 🔍+ / ズームアウト 🔍− / 実際のサイズ（1:1） / ズーム率「83%」 / 縦の区切り線 / 「リセット」 / 元に戻す ↶ / やり直し ↷ | 少し明るい背景の角丸ボックスでまとめる。リセット・元に戻す・やり直しは、編集前はグレーで無効 |
| 中央 | トリミングのアイコンだけ（選択状態を示す青い短い下線付き） | 他の5ツールは置かない。トリミングのアイコンを残すかは §8 で確認 |
| 右 | 「保存オプション ∨」（アクセントカラーのボタン）、「キャンセル」 | |

実測（スクショ上の px）：
- 左グループ：高さ約 53、ズーム系アイコンの間隔 50、元に戻す・やり直しの間隔 48
- 中央アイコンの間隔：60（参考値）
- 保存オプション：198×39、キャンセル：137×39、2つの間隔 11、右余白 約 24

### 1.3 保存オプションのメニュー 【確定】
- 「保存オプション」の直下に、ボタンの左端に揃えて表示する
- 項目（上から）：**コピーとして保存** / **保存** / **クリップボードにコピー**
- 「保存」はグレーで無効になる場合がある（条件は【未確定】）
- 背景 `#2C2C2C`、文字 `#FFFFFF`、無効時の文字は約 `#777777`

### 1.4 トリミング枠 【確定】
- 細い白の枠線、四隅に太い L 字ハンドル、各辺の中央に短いバーのハンドル
- 枠の外側の画像は暗いオーバーレイで覆う
- **ドラッグ中**：
  - 枠内に三分割のグリッド線（縦2本・横2本、1px の半透明の白い破線）を表示する
  - 枠内の下中央に、サイズを示す半透明の暗いラベル「395 x 666」を表示する
- **手を離すと**グリッドが消え、枠が画面中央に戻って、フィットするまで拡大される（ズーム率も変わる）
- **比率ピッカーを開いている間**：
  - 枠内の下中央にサイズ「422 x 316」を表示する
  - 固定比率を選んでいるときは、上中央に比率「4 : 3」も表示する（「自由」のときは出さない）
- サイズの数値は**元画像のピクセル数**で表す（画面上の px ではない）

### 1.5 角度スライダー（傾き補正） 【確定】
- 範囲：**−45° 〜 +45°**（ユーザー回答・スクショで確認）
- 正の値＝時計回り
- 値のラベルはつまみの真上。小数第1位まで表示する（例「12.4 °」）。整数ちょうどのときは「0 °」「-45 °」のように表示する
- ルーラー型：
  - **つまみは中央に固定**で、目盛りのテープのほうが左右に流れる
  - 1° ごとに小さなドット、5° ごとに長い目盛り（幅約3px・高さ約14px）
  - 間隔は約 15.2px / 1°
  - 表示するのは現在値の ±約28°（約 850px 幅）。両端はフェードアウトさせる
  - −45° より左、+45° より右には何も描かない（−45° のとき、つまみの左側は空になる）
  - 0° の位置には、つまみと重なっていなければ目盛りの代わりに数字「0」を表示する
- つまみ：白い縦長のピル形、約 10×28px

### 1.6 下部のボタン列 【確定】
- 横幅はルーラーと同じ（約 850px）で、左寄せ・中央・右寄せの3グループに分ける
- 左：反時計回りに 90° 回転 ↺、時計回りに 90° 回転 ↻（間隔約 52）
- 中央：［比率アイコン］＋現在の比率名（例「自由」）。押すと比率ピッカーが開く
- 右：左右反転 ⇄、上下反転 ⇅（間隔約 53）
- 配置：ルーラーの約 60px 下

### 1.7 比率ピッカー 【確定】
- 角度スライダーと下部ボタン列の**代わりに**表示する
- 15項目を横一列に約 100px 間隔で並べる。各項目は「アイコン＋ラベル」
- アイコンは、その比率の形をした角丸の四角（自由とオリジナルは専用アイコン）
- 選択中の項目：アイコンの背景を角丸（約 60×60）でハイライトし、ラベルを太字にする
- 一覧の下中央に「完了」

| ラベル | 比率 | ツールチップ |
|---|---|---|
| 自由 | 制約なし | 自由な縦横比 |
| オリジナル | 元画像の比率 | 元の縦横比 |
| 正方形 | 1:1 | 正方形の縦横比 |
| 9 : 16 | 9:16 | 9 x 16 の縦横比（推定） |
| 16 : 9 | 16:9 | 16 x 9 の縦横比 |
| 4 : 5 / 5 : 4 / 3 : 4 / 4 : 3 / 2 : 3 / 3 : 2 / 5 : 7 / 7 : 5 / 1 : 2 / 2 : 1 | 同左 | 「W x H の縦横比」の形（推定） |

### 1.8 ツールチップ 【確定（スタイル）】
- 背景 `#292929`、**2px の白い枠線**、角は丸めない、白い文字
- 対象ボタンの右下あたりに表示する

| 対象 | 文言 |
|---|---|
| 反時計回りに回転 | 画像を反時計回りに 90 度回転 |
| 時計回りに回転 | 画像を時計回りに 90 度回転 |
| 左右反転 | 画像を水平方向に反転 |
| 上下反転 | 画像を垂直方向に反転 |
| 角度スライダー | ドラッグするか、方向キーを使用して画像を回転 |
| トリミング枠（枠の上にカーソルを置いたとき） | ハンドルをドラッグするか、矢印キーを使用して画像をトリミングします |
| 元に戻す | 元に戻す |
| 比率ピッカーの各項目 | 1.7 の表を参照 |
| その他（ズームイン、ズームアウト、実際のサイズ、リセット、やり直し、比率ボタン、保存オプション、キャンセル） | 【未確定】ユーザーから順次受け取る |

- ツールバーのボタンにカーソルを置くと、角丸の少し明るい背景でハイライトする 【確定】

## 2. 挙動

### 2.1 角度補正
- 枠の画面上のサイズは変えずに、回転した画像が枠を完全に覆うよう、画像を自動で拡大する（83% → 112% のようにズーム率が上がる）【確定】
- 回転後の画像の外側（余白）が枠内に入ることは決してない
- スライダーは方向キーでも操作できる（ツールチップより）【確定】。1回押したときの変化量は【未確定】

### 2.2 90° 回転・反転
- 90° 回転は ↺ / ↻ の1クリックで ±90°。角度補正（±45°）と組み合わせれば、どの角度にもできる
- 左右反転・上下反転
- 回転・反転したときに枠と比率がどう変わるかは【未確定】

### 2.3 枠のドラッグ
- 四隅：2辺を同時に動かす。各辺の中央：その1辺だけ動かす
- 固定比率のときは比率を保って変形する
- 枠は回転後の画像の内側に制限する
- ドラッグ中はグリッドとサイズを表示し、離すと中央に戻して拡大する（アニメーションあり）【確定】
- 枠の内側（ハンドル以外）をドラッグしたときの動きは【未確定】
- 枠は矢印キーでも操作できる（ツールチップより）【確定】。どのキーで何が動くかは【未確定】（Windows 10 版フォトでは Shift+矢印でサイズ変更、Ctrl+矢印で移動だった）

### 2.4 比率の選択
- 比率を選ぶと、枠をその比率に変えて画面にフィットさせる（ズーム率が変わる）【確定】
- 新しい枠の大きさと位置の決め方は【未確定】（中央に置く最大サイズか、直前の枠を基準にするか）

### 2.5 ズーム
- ズームイン・ズームアウト・実際のサイズ（1:1）・ズーム率の表示
- マウスホイールの動作は【未確定】

### 2.6 リセット / 元に戻す / やり直し
- リセット：すべての編集を初期状態に戻す
- 元に戻す：Ctrl+Z、やり直し：Ctrl+Y（Windows フォトの従来のショートカット）
- 履歴の単位は、ドラッグ1回・ボタン1回・スライダー操作1回

### 2.7 保存 / キャンセル
- 書き出しは**元画像の解像度**で行い、回転・反転・切り抜きを適用する
- 割り当て（案。本家の細かい挙動は【未確定】）：
  - **コピーとして保存**：対応ブラウザでは `showSaveFilePicker`（名前を付けて保存）、それ以外はダウンロード
  - **保存**：元ファイルへの上書き。File System Access API でファイルを開いたとき（Chrome / Edge）だけ有効。ドラッグ＆ドロップや貼り付けで開いた場合は、本家と同じくグレーで無効にする
  - **クリップボードにコピー**：Clipboard API で PNG としてコピーする
- キャンセル：編集を破棄して開始画面に戻る。確認ダイアログの有無は【未確定】

## 3. Web 版独自の要素 【Web独自】
- **開始画面**：「画像を開く」ボタン（ファイル選択）、ドラッグ＆ドロップ、Ctrl+V での貼り付けに対応する。見た目は Fluent デザインに合わせる
- **テーマ切り替え**：ライト / ダーク / システム設定に従う。本家の「設定」にあたる場所として開始画面に置く。文言は本家の設定画面に合わせる（【未確定】）
- テーマの選択は `localStorage` に保存する

## 5. 技術構成（予定）
- Vite + TypeScript。UI フレームワークは使わない
- 画像の表示と書き出しは Canvas 2D
- 状態は、回転角・90° 回転回数・反転・元画像座標系での枠・比率・ズームで持つ。Undo / Redo はこの状態のスナップショットで管理する
- デプロイ：GitHub Actions → GitHub Pages（リポジトリの Settings → Pages → Source を「GitHub Actions」にする必要がある）

---

## 6. 実装上の要点（難所）
1. **回転時の自動拡大**：回転した矩形（画像）が、軸に平行な矩形（枠）を含むために必要な最小の拡大率を求める
2. **枠の制約**：ドラッグ中の枠が、回転後の画像の外にはみ出さないよう制限する（比率固定の場合も含む）
3. **フィットのアニメーション**：手を離したあと、枠を中央に戻して拡大する遷移をなめらかにする
4. **ルーラー型スライダー**：つまみを固定し、テープのほうを流す。両端はフェードさせる
5. **書き出し**：元の解像度で、回転・反転・切り抜きを正確に適用する
